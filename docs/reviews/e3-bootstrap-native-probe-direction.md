This is temporary verification only, not source implementation, a hidden model worker, installation, current-session control or end-to-end visible rollover.

1. Seed a distinct input file directly during setup; verify a vetted native read reaches the real host tool under the correct session. No baseline native write may create the designated probe output.

Never print prompts, secrets or unrelated tool content. Pin wrapper/driver/CLI/API evidence, source/compiled closure, outputs, exit/cleanup proof, actual commands and failure details.
