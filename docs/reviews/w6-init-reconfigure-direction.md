Without reconfigure, existing derived setup behavior is unchanged. `--config --reconfigure` remains explicit replacement of represented selections. Non-TTY reconfigure without --yes/--config must return accurate needs-input guidance mentioning existing config editing rather than missing configuration, without writes or unnecessary host probes.

Show actual prefilled defaults through the existing UI interface. Hosts selected while reconfiguring must affect the local machine plan; do not ask for ignored input. When local machine state is missing, create it through existing behavior, preserving shared configuration unless reconfigure was requested. Cancel/decline remains exit130 and byte-identical.
